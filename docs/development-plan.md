# 开发计划与验收

## M1 / M2：本次交付

工程基础、中文 UI 与导航、统一数据访问层、可持久化 mock、题库增改查、筛选分页、逐次问法编辑、题目来源关联及快速记录、统一公司标签配置、JSON 备份恢复和重置。面经记录和今日复习独立功能已移除。

验证命令：

```sh
pnpm typecheck
pnpm lint
pnpm format:check
pnpm test
pnpm build
```

自动测试覆盖跨字段多关键词搜索、组合筛选与分页、次数口径、新增题目→来源关联→掌握程度修改→重新读取、非法关联拒绝、损坏数据保留、恢复校验、存储写入失败、历史日期与旧备份兼容和请求层失败处理。

浏览器手工验收：

1. 新增题目及可选公司来源，保存并刷新；编辑题目信息和逐次问法，确认次数和其他记录不变。
2. 修改题目后尝试关闭；选择继续编辑应保留输入，选择放弃应关闭。
3. 输入多个关键词，再筛选题型；打开详情、返回和刷新后 URL 与筛选一致。
4. 在题目详情选择公司、填写内容，记录一次出现；题目只增加一次出现，原有来源和问法仍保留。
5. 侧栏和窄屏菜单仅有题库与数据管理；旧 /experiences、/reviews 地址返回题库，不再提供面经录入、复习和答案笔记入口。
6. 导出 JSON，再导入；旧 notes 字段保留；确认前不可替换，非法文件不可覆盖。
7. 重置演示内容需要确认；确认后回到初始种子数据。
8. 无效路由显示 404；无效题目显示题目不存在；手机导航、详情与编辑可用。
9. 点击列表公司标签选择或移除并保存；清空后不回退到来源。通过管理入口新增公司、改名换色、排序和停用，所有表单复用，往返保留草稿。点击掌握程度、整理状态和总次数修改，筛选排序同步；总次数不能少于已有逐次记录。

## M3：真实 API

协调 xuxiao-api 增加独立面经模块、数据库迁移和接口测试；将现有认证能力合理复用。真实用户数据隔离、Token 生命周期、401 和后端失败提示属于此阶段。切换 VITE_DATA_SOURCE=api 进行完整联调，不只做请求成功的页面截图。

## M4：Excel 与部署

增加上传预览、字段映射、去重与确认导入。历史累计、公司标签和掌握程度保留；无法还原的时间、公司次数不推断。先导出数据库备份，再迁移真实数据；提供导入结果和失败行。

静态构建上传现有服务器，配置 HTTPS、同源 /api 反向代理和 SPA 路由回退。验证深链接刷新与 API 404 不互相遮盖。

## M5：根据使用反馈增强

公司专题、时间范围统计、题目归并。AI 解析和预测需要真实数据与可验证的统计基础，首版不提前实现。
