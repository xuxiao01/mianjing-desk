# 面经台 · Mianjing Desk

个人面试题库。记录标准题目，以及各家公司实际问法、变形和追问。

当前交付 **M1 工程基础 + M2 可操作业务骨架**：Vue 3 / TypeScript / Vite / Naive UI / Vue Query。

## 开始使用

需要 Node.js 22.12+（开发验证环境 22.14）、pnpm 10.13.1。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开终端打印的本地地址。默认端口 5173，若被占用，可运行 `pnpm dev --port 5174`。

默认无需后端和登录，使用 **mock 演示模式**。数据仅保存在当前浏览器、当前来源地址的 localStorage；不跨设备同步。切换 localhost / 127.0.0.1 或端口，会使用独立数据。重要内容请通过「数据管理」导出 JSON。

内置 16 道示例题、2 篇示例面经和 3 条出现明细；示例日期与来源不代表真实面试记录。没有包含你的原始 Excel。

## 已支持

- 紧凑题目列表，桌面固定表头和分页；搜索、公司 / 题型 / 掌握程度 / 整理状态筛选及排序。默认每页 20 条，可选 10 / 20 / 50 条，筛选和每页数量写入 URL；实际问法仍可搜索，在详情中阅读和编辑。
- 标题右侧「沉浸阅读」在新标签页打开 `/reading`，保留当前查询条件且不显示侧栏；详情、筛选及编辑继续可用。支持的浏览器可进一步进入全屏，或点击「返回题库」回到普通布局。
- 列表公司标签可独立选择或移除，全局改名在统一管理入口完成；掌握程度和整理状态可点选修改；点击总次数修正历史累计，保留逐次记录。
- 公司标签弹窗使用单组气泡点选，勾选后统一保存；右上角图标进入全局管理。超过 12 个候选标签时显示搜索，其他录入表单保持原有选择方式。
- 搜索关键词在标题和知识点中以浅黄色高亮，支持多关键词及英文大小写匹配；公司气泡与详情保持原样，实际问法仅在详情中阅读。
- 题目详情抽屉和直接链接，显式新增 / 编辑，未保存修改的离开确认。
- 标准题目信息编辑、逐次出现记录的实际问法与追问独立编辑；公司、轮次使用统一配色气泡。
- 题目详情可直接选择公司、填写内容，快速记录一次出现；每次成功保存只增加一次，不必填写整篇面经。
- 历史累计与新增明细区分；同一篇面经的一道题只计一次，追问不增加次数。
- JSON 导出、校验后恢复、重置演示；读取损坏数据时不自动覆盖。
- 桌面布局与手机折叠菜单、全屏题目详情。

题目答案笔记功能已移除，旧 notes 字段仍原样保留在存储与备份中，不参与展示和搜索。「面经记录」「今日复习」独立页面及功能已移除，旧链接返回题库；历史来源、复习记录和复习日期仅作备份兼容，不清空旧内容。题库仍可新增来源并独立修改逐次问法和追问。没有 AI 解析、预测、账号管理、Excel 导入或真实云端保存。

## 环境配置

可复制 `.env.example` 为 `.env.local`。默认配置已可直接开发：

```dotenv
VITE_DATA_SOURCE=mock
VITE_API_BASE_URL=/api
API_PROXY_TARGET=http://127.0.0.1:3000
```

改为 `VITE_DATA_SOURCE=api` 后重启开发服务，前端会请求真实接口，错误时不会回退演示数据。**面经后端接口尚未实现，真实登录也不在当前阶段，切换 API 模式不等于完成接入。**

不要将密钥或 Token 放入 `VITE_*` 环境变量，它们会进入浏览器产物。业务接口契约及后续认证接入见 [接口约定](docs/api-contract.md)。

## 项目约定

- 按业务模块分目录；页面不直接读写 localStorage，不自行拼接接口地址。
- 所有业务读写经统一仓储接口；Vue Query 维护数据状态，保存成功后使快照查询失效。
- 普通题目编辑不修改历史统计；列表总次数修正通过独立 meta 接口校验，仅调整历史累计，不删除逐次记录。时间戳使用 ISO 字符串；历史面试日期和复习日期继续按本地日历日期读取。
- 不持久化登录密码、不伪造登录页；真实认证在 M3 对接现有后端时实施。
- 源码仓库：[xuxiao01/mianjing-desk](https://github.com/xuxiao01/mianjing-desk)。前端尚未部署，原有后端及此前目录中的其他项目未修改。

详见 [架构说明](docs/architecture.md)、[开发计划与验收](docs/development-plan.md)、[部署说明](docs/deployment.md)。

### 公司标签统一配置

在公司选择区或「数据管理」进入「管理公司标签」，统一新增、改名、选择十套实心气泡配色、调整顺序以及停用／启用公司。所有表单使用同一标签库，不再自由输入公司。配置和当前题目标签分别保存，返回表单时保留草稿。

全局改名同步题目公司标签、历史公司与面经公司名称，不改变问法、关联关系或次数。停用只隐藏新增候选项，历史展示和筛选继续可用。配置包含在 v1 JSON 备份内；旧备份首次读取时从预设和已有公司推导候选项，不自动写入或迁移数据。

公司气泡使用实心品牌近似色：百度白底黑字、腾讯蓝底白字、智谱黑底白字；字节青蓝、滴滴橙、美团黄、京东红、快手橘红。深色底配白字，明亮底配深色字。配置中还可选择紫、灰、白、黑等配色；已有配色选择仍可自行修改，不会在读取时被默认品牌色覆盖。
