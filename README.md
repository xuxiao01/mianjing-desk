# 面经台 · Mianjing Desk

共享面试题库：标准题目、公司标签、实际问法，以及无侧栏的沉浸阅读。Vue 3 / TypeScript / Vite / Naive UI / Vue Query。

本版本接入真实服务端。后端使用独立进程上线并验证认证入口后，前端再通过 main 的 GitHub Actions 发布；部署前的就绪门禁失败时保留现有站点。

## 本地启动

需要 Node.js 22.12+、pnpm 10.13.1。后端项目为 `xuxiao-api`，运行面经模块后：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

复制 `.env.example` 为 `.env.local`，用 `API_PROXY_TARGET` 指向本地后端（默认 `http://127.0.0.1:3000`）。业务数据始终从 API 读取，接口失败不会回退演示数据。生产基础路径为 `/mianjing/`，API 为同源 `/api`。

## 登录与权限

- `/login` 提供邮箱／密码和游客进入；不提供注册、密码找回，不预填或持久化密码。
- 管理员复用现有账号登录，再由 `/api/mianjing/me` 校验；服务端配置 `MIANJING_ADMIN_USER_ID=2`。
- 游客入口签发一小时只读 Token，使用独立服务端密钥；未配置时明确报错。
- Token 仅保存在专属键 `mianjing.auth.token`，刷新／新标签页可复用。退出和 401 清理会话与请求缓存，并同步其他标签页。
- 游客可以浏览、搜索、筛选及查看详情；所有写入和数据管理只向管理员开放，权限同时由服务端强制校验。

## 题库功能

- 服务端搜索、公司／题型／掌握程度／整理状态筛选及排序；普通与沉浸题库共用滚动加载，默认每批 20 条，查询条件保留在 URL。
- 分类、搜索、公司、掌握程度、整理状态、排序及每批数量自动记在当前浏览器的本地存储中，普通与沉浸页共用；不带筛选参数的入口恢复上次选择，带参数的链接以链接为准。清除筛选也会同步保存，不记录已加载批次。
- 搜索标题、知识点、公司标签及实际内容；标题和知识点安全高亮。实际问法仅在详情中展示。
- 紧凑列表、固定表头、接近底部自动追加、失败重试、沉浸新标签页、可选浏览器全屏、430px 窄屏适配。
- 沉浸页仅显示全视口表格，滚动自动加载后续题目；右下角「查找」或 `Ctrl+F`／`⌘F`／`/` 打开悬浮查询面板，筛选即时生效。普通题库保留常驻筛选与浏览器原生查找；桌面在表格内滚动，窄屏随页面滚动。
- 两处题库详情往返均保留已加载内容与阅读位置，刷新页面从首批重新加载；旧链接的 page 参数会移除。沉浸查询面板可选择每批 10／20／50 条，其更多操作可返回普通题库、切换全屏或退出登录。
- 管理员可新增／编辑标准题目，独立修改公司标签、状态和总次数；快速记录仅填写公司＋内容，编辑不增加次数。
- 新增题目时可附完整招聘类型和轮次，生成第一条记录。后续快速记录不推断这些信息。
- 删除需确认，直接生效；删除题目一并删除出现记录。公司只启用／停用。
- 公司库统一管理名称、十种实心颜色、顺序和启用状态；业务表单按公司 ID 保留草稿。
- 数据管理显示云端概况和公司管理，无本地备份、恢复或重置操作。

旧浏览器本地业务数据不会自动上传、迁移或删除。旧 mock 代码与回归用例仍独立保留，生产路由只加载 `src/modules/cloud`，不请求旧 snapshot / experiences 接口。
